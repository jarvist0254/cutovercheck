## What CutoverCheck Does

CutoverCheck provides a read-only verification workflow for PC repair shops, IT technicians, and small support teams handling a PC move. Capture an agreed baseline from selected source folders and exclusions, map destination locations, compare selected file hashes, and export a local handoff report of what was checked.

### Core Capabilities

- Capture a read-only baseline from selected folders and exclusions.
- Map source folders to destination folders across systems.
- Compare selected file hashes (SHA-256) after a migration.
- Keep manual application attestations separate from measured file results.
- Export local HTML handoff reports with full-detail or summary-only views.
