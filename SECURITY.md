# Security Policy

## Supported Releases

We actively maintain and provide security updates for the current version distributed via the Microsoft Store.

## Reporting a Vulnerability

If you discover a security vulnerability or security concern, please send a report to:
**security@jehorizon.com**

Please provide:
- A description of the issue.
- Steps or a proof-of-concept to reproduce the behavior.
- Affected application version.

We acknowledge receipt of reports within 48 hours and work diligently to issue patches through the Microsoft Store update channel.
