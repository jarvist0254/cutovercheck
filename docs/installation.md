# Installation & Setup Guide — CutoverCheck by JE Horizon

## Installing from the Microsoft Store

The easiest and most reliable way to install and keep **CutoverCheck by JE Horizon** up to date is via the official Microsoft Store:

1. Visit the store listing: [https://apps.microsoft.com/detail/9MWGM28H0KZC](https://apps.microsoft.com/detail/9MWGM28H0KZC)
2. Click **Get** or **Install in Store App**.
3. The Microsoft Store will automatically download and verify the cryptographically signed package.
4. Launch the application from your Start Menu.

## System Requirements

- **Operating System:** Windows 10 (version 19041 or higher) or Windows 11 x64. .NET 8 runtime included.
- **Architecture:** x86_64 (64-bit)
- **Disk Space:** Approximately 250 MB for installation and local database storage.

## Offline Installation & Enterprise Deployments

For air-gapped environments or managed enterprise endpoints where Microsoft Store access is restricted, contact [support@jehorizon.com](mailto:support@jehorizon.com) for certified enterprise deployment packages.
